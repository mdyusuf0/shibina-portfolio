## 🌟 Key Features & Highlights

- **100% Authentic Identity & Data**: Built strictly using Shibina's verified resume, degree attestations, IEEE certificates, and Steyp 10/10 perfect scorecards.
- **Live UAE Web Projects**: Features live links and interactive case studies for UAE e-commerce platforms developed and maintained by Shibina:
  - [`mizco.ae`](https://mizco.ae) — Enterprise Supermarket & Commercial Equipment Platform
  - [`mizhome.ae`](https://mizhome.ae) — Home Decor, Appliances & Interior Retail Platform
  - [`mizperfectsupplies.com`](https://mizperfectsupplies.com) — B2B & Commercial Supply Store
- **Gemini Premium Edge-Glow Effect**: Vibrant multi-hue animated spectrum edge-glow (`.gemini-edge-glow`) on hover across all cards, buttons, certificates, and interactive elements.
- **High-Resolution Certificates Lightbox**: Interactive gallery featuring 8 verified certificates with category filters, credential IDs, and full-screen lightbox views.
- **Responsive & Performance Optimized**: Built with React 19, Vite, and Tailwind CSS v4 for zero-lag rendering across mobile, tablet, and desktop devices.
- **Full SEO & OpenGraph**: Configured with meta tags, OpenGraph preview cards, Google Fonts (*Plus Jakarta Sans* & *Caveat*), and structured JSON-LD Person schema.

---

## 🛠️ Technology Stack

- **Core**: React 19, Vite 8, JavaScript (ES6+)
- **Styling**: Tailwind CSS v4, Custom Glassmorphism Token Architecture
- **Animations**: AOS (Animate on Scroll), Framer Motion, HTML5 Canvas Cursor Dust Particles
- **Form Integration**: EmailJS / Mailto Fallback
- **Build System**: Vite Production Bundler

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mdyusuf0/shibina-portfolio.git
   cd shibina-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview production build locally:
   ```bash
   npm run preview
   ```
